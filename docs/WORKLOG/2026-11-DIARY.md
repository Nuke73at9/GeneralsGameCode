The terrain had met the same problem before and takes the shroud in its own pass.

    - Their `ShroudTexture` and `Terrain.Shroud` (C&C4's ShroudSetup struct, which the effect loader now lets the renderer set) get it.
    - Zero Hour's extra shroud pass is left out for a mesh whose effect reads the shroud (`MaterialPassClass::Is_Shroud_Pass`, `Sage2MaterialClass::Shrouds_Itself`).
  - Meshes the effects don't draw keep Zero Hour's pass. Visual only.
